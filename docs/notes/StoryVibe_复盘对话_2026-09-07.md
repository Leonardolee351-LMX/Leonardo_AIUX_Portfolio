### 0.2 产品一句话（用户已成型、可继续打磨）

**StoryVibe = 激发用户创造力的叙事引导 Agent（tutor / 协作者）**：引导用户思考与推敲脚本，创作有深度的故事剧情；**不是** Tapnow / LibTV 类一键成片工作台。侧重引导 + 提示 +（理想上）真实生活经历取材，而非卷生成吞吐。

用户宪法级表述（已明确）：

> Agent 是 evoke user creativity 的协作者（tutor）。**不会替你直接完成任务**，但帮助提高视频创作的思考深度与创作质量。

关键用户原话（应用进案例）：

1. 「如果我对于视频创作这一块根本没有想法，我不会打开程序，而是会直接选择不做。」→ 目标用户 = **已有创作意愿的人**。  
2. 「审美，和导演思维，是决定一个片子是否与别的片子有根本差异的核心竞争力。」→ Agent **不替代**审美终审，只把导演决策显式化。

### 0.3 「中间层」定义（R1Q2 已答）

夹在 **视频剪辑 ↔ 视频生成** 之间的 **Organize 层**，主缺口是 **脚本 + 分镜结构**（不是风格一致性）。Agent 职责不是替用户减少思考，而是 **evoke 创造力**，用更轻松的方式完成「初步但有约束的思考」——类似复盘助手用问题/选项逼用户决策，从而为脚本与生成素材 prompt 提供更高质量的控制。

**诚实缺口**：可控迭代编辑当时想做、没做好——基本是让用户在 Workspace **手动改脚本**，机制未深想。

### 0.4 核心闭环与真产出（截图已证伪「主产物=视频」）

- **闭环**：`Input → Chat → Script → Generation → Community`，旁路有 **Asset** 存项目。

- **已做成（R1Q5）**：对话引导流程完整（本质偏「选择填空」）；Asset / 模板快速启动做了一部分。  
- **未做成**：真正强 Agent 推理；结构化出错检出与协作校正；深度可控迭代编辑。

### 0.5 竞争与行业反思（用户自发延展，极有价值）

- 项目约 **2026-03**，在「即梦对话 Agent」之前；半年后 **AI 漫剧暴跌**，用户反馈多「瞎掰 / 无厘头 / 本能抗拒」。若 StoryVibe 要进步，需深思背后机制，而非只加功能。  
- 无此中间层时：剧情失控、不连贯 → 反复重生成 → 成片莫名其妙 / 卡点 / 诡异 → 观看抵触。  
- 用户承认：**抵触心理成因极多**（技术、画风、剧情、一致性、出戏、快餐需求等），AI 漫剧与手工番剧差异大——这是坑，也是复盘要深挖的点。  
- 做完 **Attunia** 后，用户意识到要更多思考：Agent 能力边界、目标、出错场景、推送/任务出错后如何校正。

## 3. 助手已提出、待用户确认的框架（可直接改词）

### 3.1 五句收口

1. 中间层 = 剪辑↔生成之间的 Organize（脚本+分镜结构）。  
2. Agent 职责 = evoke + 约束决策，不是替用户少想。  
3. 主产物 = 结构化镜头脚本（Visual/Purpose/Camera/Copy + Emotion Curve）。  
4. 已做成 = Chat 引导闭环 + Script Workspace 骨架 + Asset/模板快速启动。  
5. 没做成 = 真正可控迭代编辑；Agent 深度推理；对抵触心理的系统研究。

### 3.2 指标分层（衡量「叙事脚本精度」）

- **过程**：引导完成率、决策密度、进 Workspace 后有意义编辑、局部 Revise vs 整段重来。  
- **脚本精度**：结构完备、弧线一致、下游可执行、作者认同（保存/导出）。  
- **成片/大众**：仅长期参考；不能单独当 Agent KPI。

原则：先衡量「思考是否被结构化且作者认账」，再衡量「大众是否爱看」。

### 3.3 职责边界

- Agent：决策质量与结构完备。  
- 用户：审美终审与是否发布。  
- 模型：像素级视听。

### 3.4 三种出错

1. 意图偏离 → 回约束卡 / Revise Plan。  
2. 结构错误 → 显式报错 + 修正选项。  
3. 表达不可执行 → 降级改写建议。  

现状缺口：多为手改脚本，缺自动结构检出与校正协议（可与 Attunia 复盘打通）。

### 3.5 漫剧暴跌假说层（未证实，作复盘用）

供给同质化 / 叙事缺导演思维 / 信任先验「AI=瞎掰」/ 工具奖励吞吐 / 需求与长叙事错位。
