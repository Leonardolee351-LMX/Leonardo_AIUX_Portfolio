# 首页身份与玻璃按钮细化设计

日期：2026-06-12
范围：`docs/index.html` 对应的新首页系统
状态：已确认方向，待按 spec 实施

## 1. 设计解读

Reading this as: 面向招聘者与设计审美敏感人群的个人作品集首页，在现有电影感黑色首页基础上，做更明确的身份表达与更高级的按钮材质升级，风格倾向克制、冷感、带苹果系液态玻璃启发的 premium portfolio。

本次改动不是重做首页结构，而是对首页的三处关键识别点做精修：

- 左上角与 Hero logo 的默认显示规则
- Hero 主身份文案层级
- 三个 CTA 按钮的材质语言

## 2. 目标与约束

### 目标

- 让首页主身份从偏产品导向，切换为更直接的 `Design Manager`
- 保留现有首页的版式、黑色视频氛围与品牌识别，不推翻现有系统
- 让 Hero 三个按钮从“普通玻璃按钮”升级为“有边缘厚度与折射感的 skeuomorphic glass”

### 约束

- 不改首页信息结构，不新增新的 Hero 文案块
- 不出现 `Product Manager` 的删除线、残影、过渡痕迹
- 不让按钮拟物过重到像老式水晶按钮，仍需保持当前首页的现代感
- `Vector.svg` 在首页中默认保持白色，不再因为系统浅色模式切换为黑色

## 3. 设计系统决策

### 设计拨杆

- `DESIGN_VARIANCE: 6`
- `MOTION_INTENSITY: 5`
- `VISUAL_DENSITY: 3`

解释：

- 本次不是重构页面结构，因此版式变化幅度中等
- 按钮与 logo 只做微动效，不增加新的滚动大动效
- 页面继续保持呼吸感与留白，不增加密集装饰

### 风格原则

- 主体仍为深色电影感背景
- 品牌识别维持冷白与蓝灰高光，不引入新的主色系
- 材质重点放在“玻璃边缘、顶部高光、内部雾化、轻微厚度投影”
- 页面整体坚持一个主题，不做 section 级明暗翻转

### 字体层级

- 主身份：`Design Manager`
- 副身份：`Design Engineer`
- 主身份仍沿用当前 Hero 中的高识别渐变处理
- 副身份保留但弱化一级，作为补充身份而非竞争主标题

## 4. 具体改动

### 4.1 Logo

目标：

- 首页顶部导航 logo 默认白色
- Hero 中央 logo 默认白色
- 不再受 `prefers-color-scheme: light` 自动切到黑色

执行规则：

- `.brand-mark` 默认 `background: #fff`
- 首页相关样式中移除仅针对系统浅色模式的 logo 变黑逻辑
- hover 保留现有轻微放大，不增加旋转、辉光或磁吸效果

预期结果：

- 品牌在首页深色视频背景上更稳定
- 左上角 logo 与 Hero logo 的识别一致，不会因为系统主题切换而破坏视觉统一

### 4.2 Hero 身份表达

当前问题：

- `Product Manager` 过于主导，和你现在希望的对外身份不一致
- `Design Engineer` 作为小字虽成立，但主次关系需要重新定义

新方案：

- Hero 主标题中的主身份直接替换为 `Design Manager`
- 不保留 `Product Manager` 的任何痕迹
- `Design Engineer` 继续作为次级标签保留在其下方

层级要求：

- `Design Manager` 保持当前主身份的视觉分量
- `Design Engineer` 比现在更弱一些，可通过更低不透明度、稍更小字号或更松的字距实现

不做的事情：

- 不加入删除线动画
- 不做词语切换动画
- 不加入额外职业列表

### 4.3 Hero 三按钮材质升级

目标：

- 保留当前三按钮的布局、尺寸和信息结构
- 把材质从“扁平玻璃”升级成“skeuomorphic glass”

材质定义：

- 外层边缘：更亮的玻璃高光描边
- 内层主体：半透明深色雾化玻璃
- 顶部：一层柔和的镜面高光
- 底部：轻微厚度阴影，制造悬浮感
- 内部：可有极轻的折射式亮带，但不能太花

视觉特征：

- 默认态：像被打磨过的冷色玻璃药丸按钮
- hover：边缘高光更清晰，按钮略微上浮，内部亮带稍增强
- active：按钮轻微压下，阴影收缩，体现触感

结构建议：

- 保留 `rounded-full`
- 使用双层伪元素或双层渐变实现“边框层 + 玻璃芯”
- 当前 `accent-ring` 可以保留，但需从单一 hover 边框升级为持续存在的高光边缘系统

不应出现：

- 彩虹玻璃
- 过亮霓虹描边
- 厚重白边导致按钮像塑料
- 透明度太高导致文字不清楚

## 5. 交互与动效

### Logo

- hover：`scale(1.04)` 左右即可
- 不增加位移和复杂惯性

### 按钮

- 默认：轻微内高光 + 玻璃边缘可见
- hover：
  - 向上微抬 1 到 2px
  - 边缘高光增强
  - 内部镜面感略加强
- active：
  - 轻微下压
  - scale 可在 `0.985` 到 `0.992` 范围
  - 阴影减弱

### 无障碍要求

- 按钮文字对比度必须清晰
- 不能只靠 hover 才显得可点击
- `prefers-reduced-motion` 下保留静态高光，但弱化位移与缩放动画

## 6. 实现建议

涉及文件预计为：

- `app/src/sections/v3/HeroSection3.tsx`
- `app/src/components/layout/Navigation3.tsx`
- `app/src/index.css`

建议实现方式：

- 文案替换放在 `HeroSection3.tsx`
- 默认白色 logo 的规则统一收敛到 `index.css` 的 `.brand-mark`
- skeuomorphic glass 按钮样式抽成一组可复用类，例如：
  - `glass-button-shell`
  - `glass-button-core`
  - `glass-button-sheen`

实现原则：

- 不把复杂材质写死在三个按钮的行内 class 中
- 通过组件级 class 复用，便于后续在 footer 或别处复用同一按钮语言

## 7. 风险与避免方式

### 风险 1：按钮变得太亮

避免方式：

- 高光只集中在边缘和顶部，不铺满主体
- 背景透明度控制在“可看出玻璃”但不抢文字的范围

### 风险 2：拟物过重，显得老气

避免方式：

- 保持整体配色冷静
- 不使用厚重内阴影和夸张高反差
- 让按钮仍然偏现代、克制、薄雾感

### 风险 3：主身份变更后气质失衡

避免方式：

- `Design Manager` 仍保留当前的主视觉语气
- `Design Engineer` 只做辅助，不让两者争抢焦点

## 8. 验收标准

完成后需要满足：

- 首页所有可见 logo 默认都是白色
- 主标题中不再出现 `Product Manager`
- Hero 主身份变为 `Design Manager`
- `Design Engineer` 仍在，但层级更弱
- 三个按钮明显比当前更有玻璃边缘与厚度感
- 按钮默认、hover、active 三态都成立
- 页面整体看起来像一次高质量材质升级，而不是新的风格拼贴

## 9. 本次不包含

- 不改首页 section 顺序
- 不新增 Hero 图片、标签、数据条或装饰章
- 不改导航结构
- 不对 works、about、footer 做联动重设计
- 不新增大规模 GSAP 动效
