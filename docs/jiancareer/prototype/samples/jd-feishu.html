Agent前端开发工程师 - 飞书

飞书招聘页示例 · 同源可被 Agent 读取

团队介绍：飞书是字节跳动旗下 AI 工作平台，面向人与 agent 协作，提供一站式协同办公、组织管理、业务提效工具和深入企业场景的 AI 能力。

职责

  1. 负责字节跳动飞书信任与安全相关产品的服务端研发，构建保障用户安全的平台能力与风控体系；
  2. 参与 AI 时代安全体系建设，利用大模型和 AI 工具提升威胁检测、内容安全治理、风险防控的效率与精准度；
  3. 负责团队服务质量与系统稳定性，从工具、系统、流程上持续提升开发与交付效率；
  4. 与产品、运营、法务、安全策略等多团队密切协作，推动安全能力落地与跨部门项目高效推进；
  5. 主要技术栈为 Golang。

职位要求

  1. 2027 届本科及以上，计算机、软件工程、信息安全等相关专业；
  2. 具备 AI 使用和实践经验，熟悉 Prompt 工程、AI Agent 编排或 LLM 应用开发者优先；
  3. 对外沟通协作能力强，能够跨团队推进项目；
  4. 掌握 Web 后端开发技术：协议、架构、存储、缓存、安全等。
