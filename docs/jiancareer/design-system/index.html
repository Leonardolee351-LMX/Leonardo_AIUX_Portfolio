Visual Rules

以「简职 · 注册登录基本调性」落地页为准。

01 · 标本等于页面

组件库只展示 index / login / register / upload / profile / dashboard / settings / features / about 里出现过的组件。

02 · 顶栏用同一套 PNG

Logo 用 logo-jiancareer。search / mail / bell / menu 用 icon-*.png。

03 · 按钮分两层

规格矩阵保留调性里的 12px / 高亮金。真实页面 CTA 是胶囊渐变；顶栏登录是 #00A9BC；上传主路径是橙色。

04 · 表单跟登录页

输入框左侧图标、圆角 10px、聚焦青绿环。档案页字段圆角 8px、必填红星。

05 · 首页不是岗位广场

主句「规划清楚，改好简历，一键投递」。Hero 右侧是工作台浮层，不是真实刷岗。

06 · 不编造量化

Agent 只整理简历事实。Tracker 状态来自投递记录，不用假匹配分卡片。
