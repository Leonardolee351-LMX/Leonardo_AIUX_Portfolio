项目背景

这是一份登录注册页的视效笔试题。品牌是 Light Robotics（亮源智能），口号 “Light Intelligence, embodied your real world.” 要把陪伴型机器人放进真实家庭场景里，而不是做成冷冰冰的工业面板。

完整路径很短、但必须能一口气讲完：开屏选 Login / Sign Up → 登录页在验证码、密码、指纹之间切换 → 四位验证码 → Start Journey 进入产品。信息只出现一次，社交登录和条款始终垫在底部。

设计过程

Figma 按四页推进，而不是直接画四张手机图：情绪版定感觉 → Hero 分镜写清机器人在家里发生了什么 → 设计资产把 logo / IP / 背景做成可复用件 → 交付稿把登录注册走完。面试官能从同一份文件里看见决策，而不是只看见结果。

流程演示

下面是录屏：手机样机里走完登录注册，机器人脸、霓虹绿点和玻璃拟态输入框跟着状态一起变。

设计重心

  • 机器人形象贯穿全程：开屏是家庭场景里的实体机器人，登录页用同一套 logo 与霓虹绿点把品牌钉住。
  • 验证码 / 密码 / 指纹三条通道共用一套布局，用户换方式时不换页面骨架。
  • 深色底 + 霓虹绿只服务焦点：激活的输入框、当前 Tab、主按钮，避免整屏发光。
  • 条款与社交登录始终可见，注册不另开一套视觉语言。
💡
决策：登录不是一张表单，而是带角色的品牌入口。先让用户看见机器人在真实世界里，再要求输入手机号——视效题的得分点在「形象能跟着流程走」，而不只是把输入框做圆。

关键界面

交付稿四屏：Home 开屏、Login、Verify、Start Journey。机器人形象、霓虹绿点和玻璃拟态输入框从分镜落到可点的登录注册。
